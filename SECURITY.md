# Security Policy

## Scope

This public Next.js static catalog uses GitHub Pages. Reports concerning repository supply chain, workflow credentials, catalog source poisoning, exposed secrets, script vulnerabilities, or deployment controls are in scope. Listing an external agent or MCP server does not mean the project has undergone an independent security audit.

## Report privately

Use GitHub's [private vulnerability reporting](https://github.com/CodesbyFebin/BEST-AI-AGENT-MASTER/security/advisories/new), if enabled. Otherwise contact the maintainer privately through the contact channel listed on their GitHub profile. **Do not publish exploitable payloads, keys, personal data, or active incident details in Issues.**

## Expectations

Include affected version/commit, exact file or route, reproduction that avoids real-world harm, severity rationale, and any conditions required to trigger the issue. Maintainers triage severity and coordinate mitigation; no response SLA is promised. A merged code fix is distinct from a production configuration fix.

Do not perform unauthorized penetration testing, contact upstream vendors on the maintainer's behalf, or execute submitted repositories with privileged credentials. Use safe local fixtures.

## Limitations

The repository has not established independent security certification; heuristic source scanning is not sufficient for declaring an agent safe. No repository-wide license is declared; security reporting does not grant additional redistribution rights.

See [Engineering and Operations Wiki](docs/wiki/ENGINEERING-OPERATIONS-HANDBOOK.md) and [agent scan limitations](docs/AGENT_SECURITY_SCANNING.md).
