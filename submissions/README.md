# PR-based community intake

Copy `TEMPLATE.yaml` into the matching category folder, then open a pull request. Categories: agents, bots, models, skills, mcp-servers, frameworks.

The YAML `pending` state is the default. An unverified submission does not automatically become publicly indexed; `approved` means editorial acceptance, not that feature claims, licensing or security were independently verified.

Use real upstream links, and never manufacture timestamps or SHA-256 values. If you do not have a retained source snapshot, leave `evidence.sha256` empty and `evidence.retrievedAt` empty. A correctly formatted hash does not prove a claim.

There is no submission fee, paid ranking, guaranteed review time, purchase system or runtime database in this repository.
