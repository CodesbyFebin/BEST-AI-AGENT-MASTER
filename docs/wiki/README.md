# BestAIAgent.in engineering wiki

The [Engineering, Governance, Automation and Operations Handbook](ENGINEERING-OPERATIONS-HANDBOOK.md) covers 26 sections and more than 5,000 words on:

- Planning agents, code review, GitHub workflows, and PR-based execution.
- Webhook HMAC validation, read-only runners, OIDC federation and production environments.
- Rulesets, required checks, code ownership, supply-chain risk and response.
- GitHub Pages publishing, Cloudflare operator-only redirect work, and live internet boundaries.
- MCP server permissions, catalog provenance, security scanning and source-linked publication.
- Releases, tags, responsible licensing, SEO/AEO/GEO, data freshness and verification.

**This folder is a versioned repository wiki, not GitHub's separate wiki Git repository.** Policies describe desired safeguards; they are not proof that account-level permissions or external cloud settings have been activated.
