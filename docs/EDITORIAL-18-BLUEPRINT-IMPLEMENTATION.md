## Non-negotiable editorial checks
1. Evidence must support each volatile claim. Marker syntax `[EV:<primary URL>|<specific locator>|<retrieved YYYY-MM-DD>]` is not proof on its own; inspect the cited content. Unknown is a valid answer.
2. Source-backed catalog identity does not verify product pricing, latency, licensing, security certifications, MCP transports or sovereignty.
3. A long page is appropriate only if it answers its actual visitor intent. 14,000–16,000 words and 25 internal links are targets for substantive guides, not a hard requirement for home pages, directories or legal/machine files.
4. A reference to test hours requires an actual run log. A named author or reviewer requires an actual contributor.
5. Draft structured data needs validation AND faithful correspondence to rendered visible content. FAQPage is not a guaranteed rich result. Do not mint schema entities solely to increase graph size.
6. Do not set sitemap priority based on unsourced freshness or assume Google uses the priority field. Reevaluate canonical URLs and actual `lastmod` from primary publication evidence.
7. `npm run citation:audit` in uploaded materials creates a 50-query **configuration** and does not demonstrate execution across five AI engines. The script does not exist on current `main` as of this review. Do not claim measured AI citation rate.
8. Long form user-generated content must have actual consent, moderation, attribution, spam controls and legal review. Until then, label work editorial, **not UGC**.
9. Complete verification needs npm dependencies, Next.js build, route smoke tests, link checker, crawl diagnostics, schema validation, mobile performance and search analytics after release.
