# BestAIAgent.in v2.1.1 — Maintainer and Discovery Documentation

## Maintainer publish command

```bash
gh repo set-default CodesbyFebin/BEST-AI-AGENT-MASTER
git switch main
git pull --ff-only origin main
gh run list --branch main --limit 4
gh release view v2.1.1 >/dev/null 2>&1 && { echo "v2.1.1 already exists"; exit 1; }
gh release create v2.1.1 \
  --target main \
  --title "BestAIAgent.in v2.1.1 — Maintainer and Discovery Documentation" \
  --notes-file docs/releases/v2.1.1.md \
  --latest
```

GitHub CLI will create the release and its tag if not already present. Confirm workflows for the main commit completed successfully before running the command.
